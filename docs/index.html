raft-kv-store — live Raft consensus demo

This runs a genuine reimplementation of the project's Raft algorithm — randomized-timeout leader election, AppendEntries log replication, and the §5.4.2 "commit only from the leader's own term" safety rule — entirely in the JavaScript below, simulating real network latency, message loss, crashes, and partitions. It is the same algorithm as raft/election.go and raft/replication.go, ported from Go, not a scripted animation. The production Go implementation — with its own from-scratch simulated-network test suite, a real HTTP transport, and a replicated KV store on top — lives in the GitHub repo.
